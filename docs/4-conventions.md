# Conventions de code du projet

| Aspect                                | Convention                                                                                                             |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Langue du code (variables, fonctions) | Anglais                                                                                                                |
| Langue des commentaires               | Français                                                                                                               |
| Nommage des fichiers composants React | PascalCase (`OptionsChainTable.tsx`)                                                                                   |
| Nommage des fichiers utilitaires      | kebab-case (`calculate-yield.ts`)                                                                                      |
| Linter                                | ESLint (config Next.js par défaut) + Prettier                                                                          |
| Imports                               | Alias `@/` pointant vers `src/`                                                                                        |
| Stratégie Git                         | Une branche par lot (`feature/lot-N-nom-du-lot`), mergée sur `main` après validation des critères d'acceptation du lot |
